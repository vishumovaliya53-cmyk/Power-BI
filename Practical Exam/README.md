# 📊 Student Performance Analytics Dashboard (Power BI)

## 🧾 Project Overview
This project is a Power BI dashboard designed to analyze student performance, attendance, and behavior patterns.  
It provides actionable insights for educators using interactive visuals, KPIs, and DAX measures.

---

## 📁 Dataset Description
The dataset used in this project includes the following fields:

- StudentID  
- Student Name  
- Gender  
- Class  
- Section  
- Subject  
- Score  
- Attendance  
- Term  
- Behavior Type  
- Reason  

---

## ⚙️ Data Modeling & Preparation
- Cleaned and structured student academic dataset  
- Handled relationships between tables (if applicable)  
- Created calculated columns and measures using DAX  
- Categorized performance into Low / Medium / High  

---

## 📐 DAX Measures Created
- Total Students  
- Total Behaviors  
- Average Score  
- Attendance %  
- Behavior Count  
- % Score  
- Performance Category (Low / Medium / High logic)  

---

## 📊 Dashboard Pages

### 1. Overview Dashboard
- KPI Cards:
  - Total Students
  - Average Score
  - Attendance %
  - Total Behaviors
- Visuals:
  - Average Score by Subject & Class
  - Behavior Distribution (Donut Chart)
  - Performance Insights Panel
- Filters:
  - Subject
  - Class
  - Term

---

### 2. Drill-Through / Detailed Analysis Page
- Student-wise detailed performance table
- Subject-wise score breakdown
- Behavior type mapping with reasons
- Trend analysis of % Score by Term
- Conditional formatting for performance categories

---

## 📱 Mobile View (Responsive Design)
- Created a separate **Mobile Layout** using Power BI Mobile View  
- Optimized visuals for smaller screens  
- Arranged KPIs in vertical format for better readability  
- Ensured key insights are visible without scrolling too much  
- Enabled easy navigation and interaction on mobile devices  

---

## 📈 Key Insights
- Subject-wise performance comparison across classes  
- Identification of low-performing students  
- Attendance impact on performance  
- Behavior patterns affecting academic scores  
- Term-wise performance trend analysis
